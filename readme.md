## ⛩️ Про проєкт
**«Zen Sanctuary: Sakura Shrine & Spirit Fox»** — це атмосферна інтерактивна 3D-сцена японського дзен-саду зі святилищем сакури, створена з використанням бібліотеки **Three.js**, фізичного рушія **Cannon-es**, кастомного шейдера водної поверхні на **GLSL** та 3D-моделей з анімаціями.

Проєкт повністю відповідає всім 9 обов'язковим критеріям технічного завдання:

## ✨ Реалізовані вимоги до проєкту

| № | Вимога ТЗ | Реалізація в проєкті |
|---|-----------|----------------------|
| 1 | **Примітиви** | Використано понад 6 типів геометричних примітивів Three.js: `PlaneGeometry` (гравій дзен-саду), `CylinderGeometry` (колони воріт Торії, стовбури, ліхтарі), `BoxGeometry` (перекладини Торії, сходи, зала пагоди, місток), `ConeGeometry` (багатоярусний черепичний дах), `TorusGeometry` (арка традиційного містка Taiko-bashi), `DodecahedronGeometry` (природні дзен-валуни). |
| 2 | **Складні 3D-моделі** | Інтегровано 3 моделі у форматі GLTF/GLB через `GLTFLoader`: високополігональна скульптура Храмового Дракона (`dragon.glb`, **91 216 трикутників**, Stanford Dragon) на постаменті, анімована лисиця Кіцуне (`fox.glb`) та качка (`duck.glb`). |
| 3 | **Матеріали** | Повний PBR-пайплайн (`MeshStandardMaterial` + `MeshPhysicalMaterial`): карти кольору, ARM (`aoMap`, `roughnessMap`, `metalnessMap`), `normalMap` та `displacementMap` на ґрунті; `clearcoat` лак воріт Торії; фізична рефракція та об'ємне поглинання світла (`transmission`, `ior`, `attenuationColor`) для кришталевого/нефритового дракона з картою оточення `RoomEnvironment` (`PMREMGenerator`). |
| 4 | **Освітлення** | Багаторівнева світлова схема: тепле вечірнє сонце `DirectionalLight` золотистого відтінку (#ffe6cc), м'яке розсіяне оточення `AmbientLight` рожевого сакурового тону, точкові джерела світла `PointLight` всередині кам'яних ліхтарів Тōрō з процедурним мерехтінням вогню. |
| 5 | **Тіні** | Налаштовано алгоритм м'яких тіней `THREE.PCFSoftShadowMap`. Усі об'єкти (архітектура, каміння, моделі тварин) мають коректні прапорці `castShadow` та `receiveShadow`. Камера тіней оптимізована (розмір мапи 1024x1024, ортографічні межі та налаштування `bias` / `normalBias` для уникнення артефактів тіньової смуги). |
| 6 | **Анімація** | Багатошарова система руху: скелетна анімація лисиці за допомогою `THREE.AnimationMixer` з плавним блендингом (`crossFadeTo`), кінематичний рух лисиці вздовж саду з орієнтацією `lookAt()`, плавання качечки по хвилях ставка, 380 анімованих часток опадаючих пелюсток сакури та 60 золотих світлячків. |
| 7 | **Фізика** | Повноцінний фізичний світ на базі `cannon-es` з земною гравітацією $g = -9.82\text{ м/с}^2$. Налаштовані матеріали контактів з високим тертям (0.7), що дозволяє гравцеві будувати дзен-піраміди з річкового каміння. Спавн каміння, паперових ліхтариків та сакурових куль (клавіша `SPACE` або кнопки). |
| 8 | **Якісний рендер** | Кінематографічний пост-пайплайн: тональне відображення `ACESFilmicToneMapping` з каліброваною експозицією (1.15), колірний простір `SRGBColorSpace`, вечірній атмосферний туман `THREE.FogExp2`, згладжування `antialias: true` та адаптивний `pixelRatio` (до 2). |
| 9 | **Кастомний GLSL шейдер** | Авторський `THREE.ShaderMaterial` для священного ставка Дзен: **Vertex Shader** генерує плавні синусоїдальні хвилі на сітці 64x64; **Fragment Shader** процедурно вираховує анімовану водну каустику за алгоритмами шуму Вороного, розрахунок кута Френеля для відображення неба, сонячні відблиски (specular) та глибинний градієнт прозорості. |
| 10 | **ШІ (AI-Assisted)** | Проєктування архітектури, розрахунок математичних формул водної каустики та кінематики руху створені у співпраці з ШІ. |

## 🎮 Керування сценою
- **ЛКМ + перетягування**: вільне 3D-обертання камери навколо саду (`OrbitControls`).
- **ПКМ + перетягування**: панорамування камери.
- **Колесо миші**: наближення та віддалення.
- **Клавіша SPACE** або кнопка **«🪨 Дзен-камінь»**: кинути річковий камінь у фізичний світ для побудови дзен-піраміди.
- **Кнопка «🏮 Ліхтарик»**: спавн підвісного фізичного ліхтарика.
- **Кнопка «🪵 Сакурова куля»**: спавн пружної дерев'яної кулі.
- **Кнопка «🌊 Хвиля у ставку»**: збурення амплітуди кастомного водного шейдера.
- **Кнопка «🎛️ Налаштування»**: відкриття/приховування панелі `lil-gui` для тонкого налаштування сонця, туману, хвиль, анімацій лисиці та параметрів рендера.

## 📁 Структура проєкту
```text
tp/
├── dist/                     # Готова оптимізована продакшн-збірка для хостингу
│   ├── assets/               # Мініфіковані JS-бандли та оптимізовані CSS стилі
│   └── index.html            # Зібраний HTML файл
├── src/
│   ├── index.html            # Головний HTML-шаблон та HUD
│   ├── style.css             # Стилі інтерфейсу (шрифти Cinzel, Noto Serif JP)
│   ├── script.js             # Головний файл Three.js сцени, світло, PBR, моделі, loop
│   ├── physics.js            # Фізичний рушій Дзен-саду на Cannon-es
│   ├── particles.js          # Система пелюсток сакури та золотих світлячків
│   └── shaders/
│       └── waterShader.js    # Кастомний GLSL шейдер ставка (вершинні хвилі + каустика)
├── static/                   # Статичні текстури та 3D-моделі
│   ├── models/               # fox.glb, duck.glb
│   ├── floor/                # PBR карти ґрунту саду (diff, arm, nor)
│   └── roof/                 # PBR карти даху пагоди (diff, arm, nor)
├── package.json              # Залежності: three, cannon-es, lil-gui, vite
└── vite.config.js            # Конфігурація Vite (відносний base: './')
```

## 🚀 Встановлення та запуск

```bash
# 1. Встановлення залежностей
npm install

# 2. Локальний запуск сервера розробки
npm run dev

# 3. Збірка для продакшну (GitHub Pages / Vercel)
npm run build
```

## 🌐 Хостинг (Vercel / GitHub Pages)
Проєкт повністю налаштований для миттєвого публічного розгортання:
